6.1 ROS 2 SDK 概览¶

用途¶

yobotics_sdk_ros2 是独立的 ROS 2 工作空间，其中的 sdk_ros2 包把 Yobotics 机器人运动控制能力封装为 ROS 2 节点。上层程序只需发布标准 ROS 2 消息，即可完成模式切换和速度控制。

本部分只介绍 /control_command 控制话题。机器人底层开发内容见第五部分。

控制关系¶

ROS 2 应用或命令行
        │
        │ /control_command
        ▼
yobotics_sdk_node
        │
        ▼
机器人控制器

节点收到命令后会缓存当前模式，并以 20 Hz 向机器人控制器更新控制。运动速度 超过 0.5 秒没有更新时自动归零，当前模式保持不变。

工作空间结构¶

yobotics_sdk_ros2/
├── src/
│   └── sdk_ros2/
│       ├── launch/                  # 启动文件
│       ├── msg/                     # ControlCommand 消息
│       ├── src/                     # ROS 2 节点
│       ├── vendor/yobotics_sdk/     # 随包编译的 SDK 源码
│       ├── CMakeLists.txt
│       └── package.xml
├── build/                            # 构建后生成
├── install/                          # 构建后生成
└── log/                              # 构建后生成

sdk_ros2 随包编译所需 SDK 源码，不依赖外部 libyobotics_sdk.a，因此可以单独复制工作空间并构建。

推荐阅读顺序¶

  1. 按 6.2 准备环境并完成构建。
  2. 按 6.3 启动节点并确认订阅者存在。
  3. 按 6.4 依次执行站立、切换模式和运动示例。
  4. 出现异常时按 6.5 排错，并优先进入 damp。
