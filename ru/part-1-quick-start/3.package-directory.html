1.3 Структура пакета¶

Назначение¶

Этот раздел объясняет назначение ключевых каталогов в программном пакете, чтобы пользователи могли быстро найти конфигурации, скрипты, модели, файлы SDK и примеры для разработки.

Основные каталоги¶

Путь Назначение
config.yaml Конфигурация физического робота по умолчанию
config_sim.yaml Конфигурация симуляции MuJoCo по умолчанию
actor_model/ ONNX-модели политик, используемые RL_WALK и RL_RUN
resources/ URDF робота, XML MuJoCo, mesh-файлы и другие ресурсы
scripts/ Скрипты настройки окружения, запуска симуляции, запуска физического робота, мониторинга LCM и построения графиков
mujoco_sim/ Программа симуляции MuJoCo
external_algorithms/ Python-фреймворк и примеры интеграции собственных алгоритмов
yobotics_sdk/ C++ SDK, примеры программ и HTTP-сервис управления
lcm-types/ Определения сообщений LCM и сгенерированный код

Файлы конфигурации¶

Файл Сценарий Ключевые параметры
config_sim.yaml Симуляция simulation.enable_mujoco: true, motor_communication.type: lcm
config.yaml Физический робот simulation.enable_mujoco: false, motor_communication.type: spi_legacy

Рекомендации по эксплуатации¶

  1. Если текущий сценарий неясен, сначала проверьте, используется config_sim.yaml или config.yaml.
  2. Если параметры скрипта непонятны, сначала выполните bash scripts/<script>.sh --help.
  3. После изменения LCM-сообщений заново сгенерируйте типы командой bash scripts/generate_lcm_types.sh.

Примечание по безопасности¶

Не смешивайте конфигурации симуляции и физического робота. В частности, simulation.enable_mujoco, motor_communication.type, spi_type, порты IMU и каналы LCM должны соответствовать сценарию выполнения.
