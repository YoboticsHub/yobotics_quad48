Руководство пользователя фреймворка управления четвероногим роботом Quad48¶

Это руководство помогает пользователям выполнить установку, настройку, запуск, отладку и вторичную разработку фреймворка управления четвероногим роботом Quad48.

Принципы эксплуатации¶

  • Сначала симуляция, затем физический робот: каждую новую модель, скрипт и набор параметров нужно проверить в MuJoCo или на безопасной стойке перед запуском на роботе.
  • Начинайте с конфигурации по умолчанию и меняйте параметры постепенно: не изменяйте одновременно несколько параметров связи, модели и безопасности.
  • Проверяйте алгоритм до использования робота: подтвердите порядок суставов, амплитуду действий, параметры PD, каналы LCM и вывод журналов.
  • Перед работой с физическим роботом проверьте аварийную остановку, питание, состояние площадки, кабели, IMU и конфигурацию SPI-устройств.

Основные команды¶

Ниже приведены только часто используемые команды. Перед штатной эксплуатацией прочитайте соответствующие разделы.

# Подготовить окружение Python / MuJoCo / LCM
bash scripts/setup_conda_env.sh

# Запустить симуляцию MuJoCo
bash scripts/start_mujoco.sh --config config_sim.yaml

# Запустить контроллер физического робота
bash scripts/run_robot_controller.sh --config config.yaml

# Отслеживать каналы LCM
bash scripts/monitor_lcm.sh --no-gui

Эксплуатация физического робота связана с рисками безопасности движения. Не запускайте повторно некорректную модель, скрипт или конфигурацию, пока причина проблемы не выяснена.
