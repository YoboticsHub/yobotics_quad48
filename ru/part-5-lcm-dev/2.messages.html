5.2 Определения сообщений LCM¶

Назначение¶

Этот раздел кратко описывает основные LCM-сообщения, используемые собственными алгоритмами, SDK и контроллером.

Расположение файлов¶

Файлы определений LCM находятся здесь:

lcm-types/

Основные файлы:

development_command_t.lcm
development_state_t.lcm
sport_client_cmd_t.lcm
sport_client_state_t.lcm
quad_joint_command.lcm
quad_joint_state.lcm

Команда режима разработки¶

development_command_t используется внешними алгоритмами для отправки 12-мерных команд управления суставами в контроллер.

Поле Описание
robot_id Идентификатор целевого робота
enable_development_mode 1 запускает режим разработки; 0 завершает режим разработки
joint_des_q[12] Желаемый угол сустава
joint_des_qd[12] Желаемая скорость сустава
joint_des_tau[12] Желаемый момент сустава
joint_des_kp[12] Kp сустава
joint_des_kd[12] Kd сустава

Порядок суставов: LF(hip, thigh, calf) -> RF -> LR -> RR.

Состояние режима разработки¶

development_state_t рассылается контроллером внешним алгоритмам.

Поле Описание
robot_id Идентификатор робота
joint_q[12] Угол сустава
joint_qd[12] Скорость сустава
joint_tau[12] Момент сустава
quat[4] IMU quaternion
rpy[3] roll, pitch, yaw
omega[3] Угловая скорость
acc[3] Ускорение
v_des[3] Желаемая скорость
omega_des[3] Желаемая угловая скорость
mode Текущий режим управления

Генерация типов¶

После изменения файлов .lcm выполните:

bash scripts/generate_lcm_types.sh

Примечание по безопасности¶

Размерности полей сообщений, порядок суставов и единицы измерения должны оставаться согласованными. Команды внешних алгоритмов с неверными размерностями или неверным порядком суставов могут вызвать опасное движение физического робота.
