2.3 Verify Predeployed Models¶

Purpose¶

This section explains how to verify the built-in predeployed models such as RL_WALK and RL_RUN in MuJoCo.

Prerequisites¶

  • MuJoCo simulation has been started with bash scripts/start_mujoco.sh --config config_sim.yaml.
  • ONNX model files in actor_model/ are complete.
  • The rl_walk and rl_run model paths, observation dimensions, joint dimensions, and control parameters in config_sim.yaml match the models.

Check Items¶

Item Location Description
Model path rl_walk.model_path, rl_run.model_path in config_sim.yaml Points to ONNX files under actor_model/
Observation dimension obs_dim Must match model input
Joint dimension dof_dim Current quadruped robot uses 12
Action scale action_scale Affects policy-output amplitude mapped to joint targets
PD parameters dof_kp, dof_kd Affect tracking stiffness and damping
Torque limit tau_limit Prevents excessive output

Steps¶

  1. Start simulation:
bash scripts/start_mujoco.sh --config config_sim.yaml
  1. Use the SDK or control entry point to switch to RECOVERY_STAND, then enter RL_WALK or RL_RUN.

  1. Observe the robot posture, gait, and stability in MuJoCo Viewer.
  2. Start LCM monitoring at the same time:
bash scripts/monitor_lcm.sh --no-gui
  1. To record RL data, temporarily enable the corresponding logging switch and run again.

Success Criteria¶

  • The model loads without errors.
  • The robot can enter the corresponding RL mode from a safe posture.
  • Joint position, velocity, and torque do not show abnormal spikes.
  • LCM channels keep publishing and controller logs show no NaN, Inf, or model input/output dimension errors.

Safety Note¶

If shaking, falling, excessive motion, or log errors appear in simulation, do not deploy that model to hardware. Check model path, observation construction, joint order, action scale, default joint angles, and PD parameters first.
