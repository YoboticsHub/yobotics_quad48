3.4 实物运行检查与安全停止¶

用途¶

本节给出实物运行前、中、后的检查项和异常处理方式。

运行前检查¶

检查项 要求
环境 平整、干燥、空旷，无无关人员和易碎物
电池 电量充足，无鼓包、漏液、异味和接口损坏
急停 急停按钮、遥控器急停或上位机停止命令可用
配置 config.yaml 与机器人型号、SPI、IMU、LCM 通道一致
模型 新模型、新算法已经通过仿真或安全支架验证
进程 没有旧的 SDK、WebRTC、仿真或外部算法进程占用控制通道

运行中观察¶

  • 控制器终端是否持续报错。
  • log/robot_log.txt 是否记录异常。
  • LCM 监控中状态频率是否稳定。
  • 机器人姿态、步态、关节声音和电机温度是否正常。
  • SDK、WebRTC、遥控器是否出现互相冲突的控制输入。

安全停止¶

前台运行时：

Ctrl + C

如果机器人仍在运动，应先通过遥控器、SDK、WebRTC 或上位机让机器人进入安全状态，再停止控制器。

异常处理¶

出现姿态异常、腿部抽动、控制失联、日志持续报错、异响、异味或人员靠近时：

  1. 立即发送停止、阻尼或 passive 命令。
  2. 无法停止时按下急停。
  3. 确认机器人停止后关闭总电源。
  4. 检查电池、线缆、接口、SPI、IMU 和日志。
  5. 未明确原因前不要重复运行。

禁止操作¶

  • 未做仿真验证直接运行新策略或外部算法。
  • 在机器人运动中触碰腿部、关节或机身底部。
  • 电池异常时继续使用。
  • 多个控制入口同时下发互相冲突的命令。
  • 随意增大速度、扭矩、PD 参数或关闭安全检查。
