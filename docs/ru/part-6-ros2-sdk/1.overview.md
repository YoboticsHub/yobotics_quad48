# 6.1 Обзор ROS 2 SDK

## Назначение

`yobotics_sdk_ros2` — автономное рабочее пространство ROS 2. Пакет
`sdk_ros2` предоставляет управление движением робота Yobotics через узел
ROS 2. Приложения публикуют стандартные сообщения ROS 2 для переключения
режимов и задания скорости.

В этой части описан только топик `/control_command`. Низкоуровневая
разработка робота рассматривается в части 5.

## Схема управления

```text
Приложение ROS 2 или командная строка
                 │
                 │ /control_command
                 ▼
         yobotics_sdk_node
                 │
                 ▼
        Контроллер робота
```

Узел сохраняет текущий режим и обновляет управление с частотой 20 Гц. Если
скорость не обновляется 0,5 секунды, она автоматически обнуляется, а текущий
режим сохраняется.

## Структура рабочего пространства

```text
yobotics_sdk_ros2/
├── src/
│   └── sdk_ros2/
│       ├── launch/                  # Файлы запуска
│       ├── msg/                     # Сообщение ControlCommand
│       ├── src/                     # Узел ROS 2
│       ├── vendor/yobotics_sdk/     # Исходный код SDK в составе пакета
│       ├── CMakeLists.txt
│       └── package.xml
├── build/                            # Создается при сборке
├── install/                          # Создается при сборке
└── log/                              # Создается при сборке
```

Необходимый исходный код SDK компилируется внутри `sdk_ros2`. Рабочее
пространство не зависит от внешнего `libyobotics_sdk.a` и может собираться
отдельно.

## Рекомендуемый порядок чтения

1. Подготовьте окружение и соберите пакет по разделу 6.2.
2. Запустите узел и проверьте подписчика по разделу 6.3.
3. Выполните примеры вставания, переключения режимов и движения из раздела 6.4.
4. При отклонениях используйте раздел 6.5 и сначала включите `damp`.
