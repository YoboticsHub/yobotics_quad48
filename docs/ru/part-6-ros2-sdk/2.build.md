# 6.2 Подготовка окружения и сборка

## Требования

- Ubuntu и ROS 2 Jazzy
- Компилятор C++ и `colcon`
- Eigen3 и необходимые системные библиотеки

Установите зависимости:

```bash
sudo apt update
sudo apt install liblcm-dev libeigen3-dev
```

## Сборка

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
source /opt/ros/jazzy/setup.bash

colcon build --packages-select sdk_ros2 \
  --cmake-args -DPython3_EXECUTABLE=/usr/bin/python3
```

Успешная сборка завершается сообщением:

```text
Summary: 1 package finished
```

После сборки загрузите окружение:

```bash
source install/setup.bash
```

В каждом новом терминале снова загрузите ROS 2 и рабочее пространство.

## Зачем указывать системный Python

При активном окружении Conda `base` CMake может выбрать Python из Conda,
тогда как генератор интерфейсов ROS 2 установлен для системного Python.
Параметр `-DPython3_EXECUTABLE=/usr/bin/python3` предотвращает ошибки вида
`No module named 'em'`.

## Чистая пересборка

Используйте ее только при поврежденном кэше или после изменения интерфейсов:

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
rm -rf build install log
source /opt/ros/jazzy/setup.bash
colcon build --packages-select sdk_ros2 \
  --cmake-args -DPython3_EXECUTABLE=/usr/bin/python3
source install/setup.bash
```

Для другого дистрибутива ROS 2 замените `jazzy` его фактическим именем.
