# 6.3 Запуск узла и проверка подключения

## Терминал 1: запуск узла

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
source /opt/ros/jazzy/setup.bash
source install/setup.bash

export YOBOTICS_LCM_URL='udpm://239.255.76.67:7667?ttl=255'
ros2 launch sdk_ros2 yobotics_sdk.launch.py
```

При нормальном запуске отображается сообщение:

```text
Yobotics SDK ROS2 node started at 20 Hz
```

Оставьте терминал работающим. При запуске узел находится в режиме `damp`.

## Терминал 2: загрузка окружения управления

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
source /opt/ros/jazzy/setup.bash
source install/setup.bash
```

Проверьте узел:

```bash
ros2 node list
```

В списке должен присутствовать:

```text
/yobotics_sdk_node
```

Проверьте топик управления:

```bash
ros2 topic info /control_command
```

При работающем узле число подписчиков должно быть не меньше 1. Тип сообщения:

```text
sdk_ros2/msg/ControlCommand
```

## Порядок запуска

1. Подготовьте симулятор или установите физического робота на безопасную стойку.
2. Запустите контроллер робота.
3. Запустите `yobotics_sdk_node`.
4. Убедитесь, что у `/control_command` есть подписчик.
5. Отправляйте команды режима и скорости из раздела 6.4.

Не отправляйте команды движения повторно, если узел не запущен или число
подписчиков равно нулю.
