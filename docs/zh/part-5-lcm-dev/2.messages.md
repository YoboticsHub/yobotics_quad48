# 5.2 LCM 消息定义

## 用途

本节整理自研算法、SDK 和控制器常用的 LCM 消息。

## 文件位置

LCM 定义文件位于：

```text
lcm-types/
```

常用文件：

```text
development_command_t.lcm
development_state_t.lcm
sport_client_cmd_t.lcm
sport_client_state_t.lcm
quad_joint_command.lcm
quad_joint_state.lcm
```

## 开发模式命令

`development_command_t` 用于外部算法向控制器发送 12 维关节控制命令：

| 字段 | 说明 |
| --- | --- |
| `robot_id` | 目标机器人标识 |
| `enable_development_mode` | `1` 开始开发模式，`0` 结束开发模式 |
| `joint_des_q[12]` | 期望关节角 |
| `joint_des_qd[12]` | 期望关节速度 |
| `joint_des_tau[12]` | 期望关节力矩 |
| `joint_des_kp[12]` | 关节 Kp |
| `joint_des_kd[12]` | 关节 Kd |

关节顺序为 `LF(hip, thigh, calf)（左前） -> RF（右前） -> LR（左后） -> RR（右后）`。

## 开发模式状态

`development_state_t` 用于控制器向外部算法广播状态：

| 字段 | 说明 |
| --- | --- |
| `robot_id` | 机器人标识 |
| `joint_q[12]` | 关节角 |
| `joint_qd[12]` | 关节速度 |
| `joint_tau[12]` | 关节力矩 |
| `quat[4]` | IMU 四元数 |
| `rpy[3]` | roll、pitch、yaw |
| `omega[3]` | 角速度 |
| `acc[3]` | 加速度 |
| `v_des[3]` | 期望速度 |
| `omega_des[3]` | 期望角速度 |
| `mode` | 当前控制模式 |

## 生成类型

修改 `.lcm` 文件后运行：

```bash
bash scripts/generate_lcm_types.sh
```

## 安全提示

消息字段维度、关节顺序和单位必须保持一致。外部算法发布错误维度或错误顺序的命令，可能导致实物机器人产生危险动作。
