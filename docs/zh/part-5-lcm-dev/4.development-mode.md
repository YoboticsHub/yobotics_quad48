# 5.4 开发者模式

## 用途

开发者模式允许 Python 外部算法通过 LCM 接收机器人状态，并发布 12 维关节命令。控制器只有进入 `DEVELOPMENT` 模式后，才会响应开发模式命令。

## 前提

- 控制器已启动。
- SDK、遥控器或其他控制入口可以切换到 `DEVELOPMENT`。
- 外部算法配置中的 `robot_id`、`state_channel`、`command_channel` 与控制器一致。
- MuJoCo 或实物端 LCM 网络正常。

## 工作流程

1. 控制器运行并广播当前状态。
2. SDK 或控制入口将控制模式切换到 `DEVELOPMENT`。
3. 外部算法订阅 `Y15_development_state`。
4. 外部算法发布 `Y15_development_command`。
5. 控制器校验模式和命令后执行关节控制。
6. 外部算法结束时发布禁用命令或安全命令。

## 进入开发模式
```bash
./yobot_sport_client ->按 5 进入 DEVELOPMENT，具体以 SDK 键盘为准。
```

SDK 中模式编号：

| 编号 | 模式 |
| --- | --- |
| `1005` | `DEVELOPMENT` |

进入开发模式后再运行 Python 开发包：

```bash
python3 external_algorithms/wave_algorithm/run_algorithm.py --config external_algorithms/wave_algorithm/config.yaml
```

## 成功标志

- 外部算法能持续收到 `development_state_t`。
- 控制器处于 `DEVELOPMENT` 模式。
- `monitor_lcm.sh` 能看到开发模式状态和命令通道。
- 算法退出时机器人能回到安全状态。

## 控制器侧逻辑

控制器侧入口在 FSM_State_Development.cpp。只有 FSM 处于 DEVELOPMENT，且命令中的 robot_id 与控制器配置一致、enable_development_mode 为 1 时，外部命令才会写入 12 个关节目标。

| 逻辑 | 说明 |
| --- | --- |
| 状态发布 | 发布 development_state_t 到 Y15_development_state |
| 命令订阅 | 订阅 development_command_t 的 Y15_development_command |
| robot_id 检查 | 不匹配的命令直接忽略 |
| enable_development_mode | 1 表示外部接管，0 表示结束外部接管 |
| 50 ms 超时 | 激活后超过 50 ms 没有新命令，自动结束外部接管 |
| 自检 | 退出外部接管后检查 roll/pitch，失败则清零控制命令 |

控制器会把 joint_des_q、joint_des_qd、joint_des_tau、joint_des_kp、joint_des_kd 直接写入关节目标。因此 Python 算法发布的数组必须已经是最终可执行命令。

## 配置含义

控制器和外部算法必须使用相同的 robot_id: Y15、Y15_development_state 和 Y15_development_command。lcm.url 为空时使用默认 URL；跨机器或多网卡异常时，先检查 LCM 网络，再用监控脚本验证。

## 完整运行时序

| 阶段 | 操作 | 期望现象 |
| --- | --- | --- |
| 1 | 启动控制器 | 能发布状态 |
| 2 | 切换到 DEVELOPMENT | FSM 进入开发者模式 |
| 3 | 启动算法 | 加载配置并订阅状态 |
| 4 | 收到第一帧状态 | 自动开始，先用当前关节角接管 |
| 5 | 推理或规则计算 | 更新最近一次 12 维命令 |
| 6 | LCM 发送线程 | 按配置频率发送，最高 200 Hz |
| 7 | 退出算法 | 发送禁用命令，控制器退出外部接管 |

## 常见问题

| 现象 | 可能原因 | 排查方法 |
| --- | --- | --- |
| 命令有数据但机器人不动 | FSM 未进入 DEVELOPMENT | 确认 SDK 模式编号 1005 |
| 控制器忽略命令 | robot_id 不一致 | 核对控制器和算法配置 |
| 动一下就退出 | 命令间隔超过 50 ms | 检查 LCM 网络和发送频率 |
| 退出后清零 | roll/pitch 自检失败 | 检查 IMU、姿态和控制器日志 |

注意：示例默认常为 "Y15"，但这是匹配用字符串，不等于机型只能是 Y15；
## 安全提示

不要在非 `DEVELOPMENT` 模式下假设外部算法命令会生效。实物运行时，进入开发者模式前必须确认机器人姿态稳定、速度命令为零、人员远离机器人。
