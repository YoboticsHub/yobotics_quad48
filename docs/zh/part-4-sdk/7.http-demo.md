# 4.7 SDK HTTP 控制服务

## 用途

本节说明 SDK HTTP 示例服务的用途和基本调用方式。该服务适合上位机、Web 系统或集成测试通过 HTTP 间接发送控制命令。

## 前提

- SDK 已编译完成（详见4.2章节）。
- 控制器已启动，并能通过 LCM 接收 SDK 命令。
- HTTP 服务端与控制器使用同一 LCM URL。

## 启动服务

```bash
cd yobotics_sdk/build
./yobot_http_server
```

如需指定 LCM URL：

```bash
export YOBOTICS_LCM_URL="udpm://239.255.76.67:7667?ttl=255"
./yobot_http_server
```

## 常用接口示例

查询状态：

```bash
curl -X GET "http://192.168.1.100:8080/control/status"   -H "Authorization: Bearer E15_Robot_Secure_Token_123"
```

进入阻尼模式：

```bash
curl -X POST "http://192.168.1.100:8080/control/motion"   -H "Authorization: Bearer E15_Robot_Secure_Token_123"   -H "Content-Type: application/json"   -d "{"mode":"damp"}"
```

停止运动：

```bash
curl -X POST "http://192.168.1.100:8080/control/stop"   -H "Authorization: Bearer E15_Robot_Secure_Token_123"
```

## 成功标志

- HTTP 服务正常监听端口。
- 状态查询能返回机器人状态。
- 控制请求能在 LCM 监控中看到对应控制消息。

## 安全提示

HTTP token、监听地址和端口应按现场网络安全要求修改。不要把控制服务暴露到不可信网络。
