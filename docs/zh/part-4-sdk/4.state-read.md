# 4.4 SDK 状态读取控制流程

## 用途

本节说明如何通过 SDK 读取机器人状态，用于上位机显示、业务逻辑判断和联调排查。

## 前提

- 控制器已运行。
- SDK 已编译完成（详见4.2章节）。
- `QUAD_ROBOT_STATE` 通道与控制器配置一致。

## 示例程序

状态读取示例源码：

```text
yobotics_sdk/example/robot_state_client.cpp
```

编译后的程序：

```text
yobotics_sdk/build/yobot_robot_state_client
```

## 运行方式

```bash
cd yobotics_sdk/build
./yobot_robot_state_client
```

指定 LCM URL：

```bash
export YOBOTICS_LCM_URL="udpm://239.255.76.67:7667?ttl=255"
./yobot_robot_state_client
```

## 可读取状态

| 状态 | 用途 |
| --- | --- |
| 当前控制模式 | 判断机器人处于 DAMP、RECOVERY、RL 或 DEVELOPMENT |
| 速度和姿态信息 | 上位机显示和运动状态判断 |
| 控制反馈 | 确认 SDK 命令是否被控制器接收 |
| 关节状态通道 | 调试底层关节位置、速度和力矩 |

## 成功标志

- 程序持续输出状态。
- 模式、速度、姿态等字段随控制器状态变化（详见4.3章节）。
- LCM 监控中可见 `QUAD_ROBOT_STATE`（详见2.4章节）。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 程序无输出 | 检查控制器是否启动/LCM URL是否与控制器一致|
| 状态频率很低 | 检查网络和 CPU 负载 |
| 字段值不变化 | 检查是否订阅了正确通道 |
