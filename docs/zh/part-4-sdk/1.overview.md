# 4.1 SDK 代码目录与功能

## 用途

SDK 用于高层二次开发，封装底层 LCM 通信，让用户通过 C++ 示例完成运动控制、状态读取和 HTTP 控制服务。

## 代码目录

| 路径 | 作用 |
| --- | --- |
| `yobotics_sdk/include/` | SDK 头文件、LCM 类型、通道封装、机器人接口 |
| `yobotics_sdk/example/` | 运动控制、状态读取、HTTP 服务示例 |
| `yobotics_sdk/tools/` | SDK 打包、发送到板端、版本和交叉编译工具 |
| `yobotics_sdk/CMakeLists.txt` | SDK 编译入口 |
| `yobotics_sdk/SDK使用说明.md` | 原始 SDK 使用说明 |

SDK使用说明.md 为 SDK 包内原始说明，冲突时以本手册为准。
## SDK 功能

- 封装 LCM 发布和订阅。
- 向 `QUAD_ROBOT_CONTROL` 发布高层运动命令。
- 从 `QUAD_ROBOT_STATE` 读取机器人状态。
- 支持关节状态和关节命令镜像通道。
- 提供 HTTP 服务示例，方便上位机或 Web 系统调用。

## 常用通道

| 通道 | 作用 |
| --- | --- |
| `QUAD_ROBOT_CONTROL` | SDK 控制下发 |
| `QUAD_ROBOT_STATE` | 机器人状态回读 |
| `leg_control_data` | 关节状态 |
| `leg_control_command` | 关节命令镜像 |
| `Y15_development_state` | 开发模式状态 |
| `Y15_development_command` | 开发模式命令 |

开发模式通道名沿用 Y15_ 前缀，与 SPI 板类型 / 机型无关；E15 实物同样使用（详见 5.1 章节/ 5.4章节）。
## 前提

- 控制框架启用 LCM 控制方式。
- SDK 与控制器使用一致的 LCM URL。
- 网络允许 UDP 组播。
- 控制器侧 `gamepad.lcm_control_channel` 和 `gamepad.lcm_state_channel` 与 SDK 通道一致。

## 安全提示

SDK 只负责通信和命令发送，不会自动判断机器人是否处于安全姿态。实物控制前必须先确认机器人状态、速度限幅和急停能力。
