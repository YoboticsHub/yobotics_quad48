# 4.3 SDK 运动控制使用流程

## 用途

本节说明如何通过 SDK 发送高层运动控制命令。

## 前提

- 控制器已在仿真或实物环境中启动。
- SDK 已编译完成。
- SDK 与控制器使用同一 LCM URL。
- 机器人处于可接收高层控制的模式，如 `gamepad->device_type`:`hybrid` 或`lcm`。

## 示例程序

运动控制示例源码：

```text
yobotics_sdk/example/sport_client.cpp
```

编译后的程序：

```text
yobotics_sdk/build/yobot_sport_client
```

## 运行方式

```bash
cd yobotics_sdk/build
./yobot_sport_client
```
## 运行结果

如需指定 LCM URL：

```bash
export YOBOTICS_LCM_URL="udpm://239.255.76.67:7667?ttl=255"
./yobot_sport_client
```

## 常用控制字段

| 字段 / 接口 | 作用 |
| --- | --- |
| `Move(vx, vy, vyaw)` | 设置前后、横移和 yaw 速度 |
| `BodyHeight(h)` | 设置机身高度命令 |
| `Euler(roll, pitch)` | 设置机身姿态命令 |
| API编号 `1000` | `PASSIVE` |
| API编号 `1001` | `DAMP` |
| API编号 `1002` | `RL_WALK` |
| API编号 `1003` | `RL_RUN` |
| API编号 `1005` | `DEVELOPMENT` |
| API编号 `1006` | `RECOVERY_STAND` |
| API编号 `1007` | `STAND_DOWN` |

可复制控制流程：PASSIVE->DAMP->STAND_DOWN->RECOVERY_STAND...
## 成功标志

- 控制器能收到 `QUAD_ROBOT_CONTROL`。
- 状态回读通道能看到模式和速度命令变化。
- 仿真或实物机器人按限幅后的速度响应。

## 安全提示

实物测试时从小速度开始，例如先测试低幅值 `vx`、`vy`、`vyaw`。不要在未验证情况下直接发送大速度、快速模式切换或机身姿态大幅命令。
