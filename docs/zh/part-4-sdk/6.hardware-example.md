# 4.6 SDK 控制实物例子

## 用途

本节说明如何用 SDK 控制真实机器人。

## 前提

- 实物控制器已通过 `bash scripts/run_robot_controller.sh --config config.yaml` 启动。
- 机器人已进入安全姿态,例如当前机器人处于被动/阻尼状态。
- SDK 机器与机器人端网络互通。
- SDK 与控制器使用同一个 LCM URL。
- 速度限幅、安全检查和急停已确认。

## 操作步骤

### 1. 在机器人端启动控制器
```bash
#ssh连接机器人
ssh cat@机器人IP（例如：192.168.1.100）
```

```bash
bash scripts/run_robot_controller.sh --config config.yaml
```

### 2. 在 SDK 端设置 LCM URL

```bash
export YOBOTICS_LCM_URL="udpm://239.255.76.67:7667?ttl=255"
```

### 3. 读取状态

```bash
cd yobotics_sdk/build
./yobot_robot_state_client
```

### 4. 发送小幅运动命令

```bash
cd yobotics_sdk/build
./yobot_sport_client
```
![](image/res_2.png)
推荐操作顺序：DAMP->RECOVERY_STAND->RL_WALK->STAND_DOWN，
建议先从低速度、短时间命令开始测试。
## 成功标志

- 状态读取稳定。
- 控制器日志无 LCM、SPI、IMU 错误。
- 机器人按小幅命令响应，并能随时停止或进入阻尼 / passive。

## 安全提示

实物测试时不要让 SDK、WebRTC、遥控器和外部算法同时发送冲突命令。出现异常动作时立即停止命令并使用急停。
