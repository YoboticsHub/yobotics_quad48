# 6.2 环境准备与构建

## 系统要求

- Ubuntu 与 ROS 2 Jazzy
- C++ 编译器和 `colcon`
- Eigen3 与构建所需系统库

安装依赖：

```bash
sudo apt update
sudo apt install liblcm-dev libeigen3-dev
```

## 构建

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
source /opt/ros/jazzy/setup.bash

colcon build --packages-select sdk_ros2 \
  --cmake-args -DPython3_EXECUTABLE=/usr/bin/python3
```

构建成功时应看到：

```text
Summary: 1 package finished
```

构建完成后加载工作空间：

```bash
source install/setup.bash
```

每个新终端都需要重新加载 ROS 2 和工作空间环境。

## 为什么指定系统 Python

如果终端处于 Conda `base` 环境，CMake 可能选择 Conda Python，而 ROS 2
接口生成器安装在系统 Python 中。显式设置
`-DPython3_EXECUTABLE=/usr/bin/python3` 可以避免
`No module named 'em'` 等错误。

## 干净重建

仅在构建缓存异常或接口定义发生变化时执行：

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
rm -rf build install log
source /opt/ros/jazzy/setup.bash
colcon build --packages-select sdk_ros2 \
  --cmake-args -DPython3_EXECUTABLE=/usr/bin/python3
source install/setup.bash
```

如果使用其他 ROS 2 发行版，将命令中的 `jazzy` 替换为实际发行版名称。
