# 6.3 启动节点与连接检查

## 终端 1：启动节点

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
source /opt/ros/jazzy/setup.bash
source install/setup.bash

export YOBOTICS_LCM_URL='udpm://239.255.76.67:7667?ttl=255'
ros2 launch sdk_ros2 yobotics_sdk.launch.py
```

正常启动时会看到类似日志：

```text
Yobotics SDK ROS2 node started at 20 Hz
```

保持该终端运行。节点启动后默认处于 `damp` 模式。

## 终端 2：加载控制环境

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
source /opt/ros/jazzy/setup.bash
source install/setup.bash
```

检查节点：

```bash
ros2 node list
```

应能看到：

```text
/yobotics_sdk_node
```

检查控制话题：

```bash
ros2 topic info /control_command
```

节点正常运行时，输出中的订阅者数量应至少为 1。消息类型应为：

```text
sdk_ros2/msg/ControlCommand
```

## 启动顺序

1. 准备仿真环境或将实体机器人放置在安全支架上。
2. 启动机器人控制器。
3. 启动 `yobotics_sdk_node`。
4. 确认 `/control_command` 存在订阅者。
5. 再发送 6.4 中的模式和速度命令。

不要在节点启动失败或订阅者数量为 0 时反复发送运动命令。
