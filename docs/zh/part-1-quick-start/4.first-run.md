# 1.4 初次使用流程

## 用途

本节给出第一次使用软件包时的推荐顺序，避免直接跳到实物运行造成排查困难或安全风险。

## 前提

- 已进入项目根目录（详见1.3软件包目录-目录结构）。
- 已安装 Conda 或具备 Python 运行环境（详情见1.2章节）。
- 当前机器可以访问软件包中的 `scripts/`、`config_sim.yaml` 和 `resources/`。

## 操作步骤

### 1. 准备环境

```bash
bash scripts/setup_conda_env.sh
conda activate robot_controller
```

### 2. 启动 MuJoCo 仿真（详情见2.2 启动仿真）

```bash
bash scripts/start_mujoco.sh --config config_sim.yaml
```


### 3. 检查 LCM 通信（另开终端）
```bash
conda activate robot_controller
```
```bash
bash scripts/monitor_lcm.sh --no-gui
```

### 4. 编译并运行 SDK 示例（SDK 编译详见4.2章节）
```bash
cd yobotics_sdk
mkdir -p build
cd build
cmake ..
make -j4
./yobot_sport_client
```
```bash
./yobot_sport_client 启动后行为见4.3章节
```
### 5. 实物运行前检查

切换到真实机器人前，先核对：

- `config.yaml` 中 `simulation.enable_mujoco: false`。
- `motor_communication.type`、`spi_type`、SPI 设备和 IMU 端口正确。
- 急停、供电、电池、地面环境和安全区域已确认。
- 新模型或新算法已完成仿真验证。

## 成功标志

- MuJoCo 仿真器和控制器持续运行。
- LCM 监控能看到通道和消息频率。
- SDK 示例可以发送控制命令或读取状态，对应的仿真机器人有相符动作行为。
- 控制器日志没有资源缺失、库缺失、Python 导入失败或通信初始化失败。

## 安全提示

首次使用不要修改速度上限、扭矩限制、PD 参数和安全检查开关。确认默认链路稳定后，再逐项调整。
