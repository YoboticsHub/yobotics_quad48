# 6.1 ROS 2 SDK Overview

## Purpose

`yobotics_sdk_ros2` is a standalone ROS 2 workspace. Its `sdk_ros2` package
exposes Yobotics robot motion control through a ROS 2 node. Applications publish
standard ROS 2 messages to switch modes and command velocity.

This part documents only the `/control_command` topic. See Part 5 for
low-level robot development.

## Control Relationship

```text
ROS 2 application or command line
              │
              │ /control_command
              ▼
      yobotics_sdk_node
              │
              ▼
       Robot controller
```

The node caches the current mode and updates the robot controller at 20 Hz. If
motion velocity is not refreshed for 0.5 seconds, velocity returns to zero while
the current mode remains active.

## Workspace Layout

```text
yobotics_sdk_ros2/
├── src/
│   └── sdk_ros2/
│       ├── launch/                  # Launch files
│       ├── msg/                     # ControlCommand message
│       ├── src/                     # ROS 2 node
│       ├── vendor/yobotics_sdk/     # SDK sources built with the package
│       ├── CMakeLists.txt
│       └── package.xml
├── build/                            # Generated after build
├── install/                          # Generated after build
└── log/                              # Generated after build
```

The required SDK sources are compiled inside `sdk_ros2`. The workspace does
not depend on an external `libyobotics_sdk.a` and can be copied and built
independently.

## Recommended Reading Order

1. Prepare and build the workspace using Section 6.2.
2. Start the node and verify its subscriber using Section 6.3.
3. Follow the standing, mode-switching, and motion examples in Section 6.4.
4. If anything is abnormal, use Section 6.5 and switch to `damp` first.
