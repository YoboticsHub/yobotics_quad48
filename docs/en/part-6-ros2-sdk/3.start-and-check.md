# 6.3 Start the Node and Check the Connection

## Terminal 1: Start the Node

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
source /opt/ros/jazzy/setup.bash
source install/setup.bash

export YOBOTICS_LCM_URL='udpm://239.255.76.67:7667?ttl=255'
ros2 launch sdk_ros2 yobotics_sdk.launch.py
```

A normal startup prints a message similar to:

```text
Yobotics SDK ROS2 node started at 20 Hz
```

Keep this terminal running. The node starts in `damp` mode.

## Terminal 2: Load the Control Environment

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
source /opt/ros/jazzy/setup.bash
source install/setup.bash
```

Check the node:

```bash
ros2 node list
```

The output should include:

```text
/yobotics_sdk_node
```

Check the control topic:

```bash
ros2 topic info /control_command
```

When the node is running, the subscription count should be at least 1. The
message type should be:

```text
sdk_ros2/msg/ControlCommand
```

## Startup Order

1. Prepare the simulator or place the physical robot on a safety stand.
2. Start the robot controller.
3. Start `yobotics_sdk_node`.
4. Confirm that `/control_command` has a subscriber.
5. Send the mode and velocity commands from Section 6.4.

Do not repeatedly send motion commands when node startup has failed or the
subscription count is zero.
