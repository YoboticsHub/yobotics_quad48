# 6.4 `/control_command` Modes and Motion Examples

## Message Structure

`/control_command` uses:

```text
sdk_ros2/msg/ControlCommand
```

| Field | Meaning |
| --- | --- |
| `mode` | Control mode |
| `cmd_vel.linear.x` | Forward/backward velocity; positive is forward |
| `cmd_vel.linear.y` | Lateral velocity |
| `cmd_vel.angular.z` | Turning angular velocity |

Supported modes are `passive`, `damp`, `recovery_stand`,
`stand_down`, `rl_walk`, and `development`. Velocity is effective only
in `rl_walk` and `development`.

## `--once` and `--rate`

- Use `--once` for a one-time mode switch.
- Use `--rate 10` to continuously publish motion velocity at 10 Hz.
- Velocity automatically returns to zero after 0.5 seconds without an update,
  while the current mode remains active.

## Recommended Sequence

### 1. Stand Up

```bash
ros2 topic pub --once \
  /control_command \
  sdk_ros2/msg/ControlCommand \
  "{mode: recovery_stand, cmd_vel: {}}"
```

Wait until the robot is fully stable before switching modes.

### 2. Switch to `rl_walk`

```bash
ros2 topic pub --once \
  /control_command \
  sdk_ros2/msg/ControlCommand \
  "{mode: rl_walk, cmd_vel: {}}"
```

This switches the mode without moving the robot.

### 3. Move Forward Continuously

```bash
ros2 topic pub --rate 10 \
  /control_command \
  sdk_ros2/msg/ControlCommand \
  "{mode: rl_walk, cmd_vel: {linear: {x: 0.1, y: 0.0, z: 0.0}, angular: {z: 0.0}}}"
```

After pressing `Ctrl+C`, velocity returns to zero within about 0.5 seconds.

### 4. Switch to `damp`

```bash
ros2 topic pub --once \
  /control_command \
  sdk_ros2/msg/ControlCommand \
  "{mode: damp, cmd_vel: {}}"
```

## Other Motion Examples

Move laterally:

```bash
ros2 topic pub --rate 10 /control_command sdk_ros2/msg/ControlCommand \
  "{mode: rl_walk, cmd_vel: {linear: {x: 0.0, y: 0.1, z: 0.0}, angular: {z: 0.0}}}"
```

Turn in place:

```bash
ros2 topic pub --rate 10 /control_command sdk_ros2/msg/ControlCommand \
  "{mode: rl_walk, cmd_vel: {linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {z: 0.2}}}"
```

Stop motion while keeping `rl_walk`:

```bash
ros2 topic pub --rate 10 /control_command sdk_ros2/msg/ControlCommand \
  "{mode: rl_walk, cmd_vel: {}}"
```

Start with low values and verify forward, lateral, and turning directions
individually.
