# 6.2 Environment Setup and Build

## Requirements

- Ubuntu with ROS 2 Jazzy
- A C++ compiler and `colcon`
- Eigen3 and the required system libraries

Install the dependencies:

```bash
sudo apt update
sudo apt install liblcm-dev libeigen3-dev
```

## Build

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
source /opt/ros/jazzy/setup.bash

colcon build --packages-select sdk_ros2 \
  --cmake-args -DPython3_EXECUTABLE=/usr/bin/python3
```

A successful build ends with:

```text
Summary: 1 package finished
```

Load the workspace after the build:

```bash
source install/setup.bash
```

Load both ROS 2 and the workspace again in every new terminal.

## Why the System Python Is Specified

When a Conda `base` environment is active, CMake may select the Conda Python
while the ROS 2 interface generator is installed for the system Python.
Setting `-DPython3_EXECUTABLE=/usr/bin/python3` avoids errors such as
`No module named 'em'`.

## Clean Rebuild

Use this only when the build cache is invalid or an interface definition has
changed:

```bash
cd ~/yobotics_quad48/yobotics_sdk_ros2
rm -rf build install log
source /opt/ros/jazzy/setup.bash
colcon build --packages-select sdk_ros2 \
  --cmake-args -DPython3_EXECUTABLE=/usr/bin/python3
source install/setup.bash
```

For another ROS 2 distribution, replace `jazzy` with the installed
distribution name.
