# 4.1 SDK Directory and Features

## Purpose

The SDK supports high-level secondary development. It wraps low-level LCM communication so users can complete motion control, state reading, and HTTP control-service integration through C++ examples.

## Code Directories

| Path | Purpose |
| --- | --- |
| `yobotics_sdk/include/` | SDK headers, LCM types, channel wrappers, robot interfaces |
| `yobotics_sdk/example/` | Motion-control, state-reading, and HTTP-service examples |
| `yobotics_sdk/tools/` | SDK packaging, board deployment, version, and cross-build tools |
| `yobotics_sdk/CMakeLists.txt` | SDK build entry |
| `yobotics_sdk/SDK_User_Guide.md` | English SDK usage guide |

If there is any conflict, this manual takes precedence over the original package notes.

## SDK Features

- Wraps LCM publish and subscribe logic.
- Publishes high-level motion commands to `QUAD_ROBOT_CONTROL`.
- Reads robot state from `QUAD_ROBOT_STATE`.
- Supports joint-state and joint-command mirror channels.
- Provides an HTTP service example for upper computers or Web systems.

## Common Channels

| Channel | Purpose |
| --- | --- |
| `QUAD_ROBOT_CONTROL` | SDK control command |
| `QUAD_ROBOT_STATE` | Robot state feedback |
| `leg_control_data` | Joint state |
| `leg_control_command` | Joint command mirror |
| `Y15_development_state` | Development-mode state |
| `Y15_development_command` | Development-mode command |

The `Y15_` prefix in development-mode channels is historical and is not tied to the SPI board type or robot model. E15 hardware also uses these channels unless the configuration is changed.

## Prerequisites

- The control framework uses LCM control.
- SDK and controller use the same LCM URL.
- The network allows UDP multicast.
- Controller-side `gamepad.lcm_control_channel` and `gamepad.lcm_state_channel` match the SDK channels.

## Safety Note

The SDK only handles communication and command sending. It does not determine whether the robot is in a safe posture. Before controlling hardware, confirm robot state, velocity limits, and emergency-stop capability.
