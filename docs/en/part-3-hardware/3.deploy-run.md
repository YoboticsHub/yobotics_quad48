# 3.3 Deploy and Run on a Physical Robot

## Purpose

This section explains how to send the deployment package to the robot side and start the physical controller.

## Prerequisites

- Simulation verification is complete.
- `config.yaml` has been checked for the physical robot.
- Battery, emergency stop, cables, ground environment, and safety area are confirmed.
- The robot-side network is reachable.

## Deploy the Program

Send the program to the robot. Script parameters and target addresses depend on the site configuration. After sending, confirm that controller, libraries, configuration, models, and resources are complete.

```bash
# 1. Log in through SSH, for example:
ssh username@robot_ip

# 2. Send a compiled file
scp local_file username@robot_ip:/remote/target/path/

# 3. Send a directory
scp -r local_folder username@robot_ip:/remote/target/path/
```

## Start the Hardware Controller

Run from the project root on the robot side:

```bash
bash scripts/run_robot_controller.sh --config config.yaml
```

The script selects paths from `uname -m`:

| Architecture | Controller directory | Library directory |
| --- | --- | --- |
| `x86_64` | `bin/ybt_ctrl` | `lib/` |
| `aarch64` / `arm64` | `bin_rk3588/ybt_ctrl` | `lib_rk3588/` |

## Runtime Sequence

1. Keep the robot in a safe mode after controller startup.
2. Confirm that logs contain no SPI, IMU, library, or configuration errors.
3. Enter `RECOVERY_STAND` through the remote controller, SDK, or upper computer.
4. After posture is stable, enter motion modes such as `RL_WALK`.
5. To test external algorithms, enter `DEVELOPMENT` first.

## Success Criteria

- The controller starts and keeps running.
- Terminal output shows correct configuration, executable, and library paths.
- No SPI, IMU, or LCM initialization failure occurs.
- The robot can enter a safe posture and LCM state can be monitored.

## Safety Note

`run_robot_controller.sh` currently configures LCM multicast routing for `eth1`. If the site network interface differs, adjust multicast configuration first. If abnormal posture, unusual sound, loss of control, twitching, or continuous log errors occur, stop immediately.
