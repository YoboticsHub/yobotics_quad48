# 5.2 LCM Message Definitions

## Purpose

This section summarizes common LCM messages used by custom algorithms, the SDK, and the controller.

## File Location

LCM definition files are under:

```text
lcm-types/
```

Common files:

```text
development_command_t.lcm
development_state_t.lcm
sport_client_cmd_t.lcm
sport_client_state_t.lcm
quad_joint_command.lcm
quad_joint_state.lcm
```

## Development-Mode Command

`development_command_t` is used by external algorithms to send 12-dimensional joint-control commands to the controller.

| Field | Description |
| --- | --- |
| `robot_id` | Target robot identifier |
| `enable_development_mode` | `1` starts development mode; `0` ends development mode |
| `joint_des_q[12]` | Desired joint angle |
| `joint_des_qd[12]` | Desired joint velocity |
| `joint_des_tau[12]` | Desired joint torque |
| `joint_des_kp[12]` | Joint Kp |
| `joint_des_kd[12]` | Joint Kd |

Joint order is `LF(hip, thigh, calf) -> RF -> LR -> RR`.

## Development-Mode State

`development_state_t` is broadcast by the controller to external algorithms.

| Field | Description |
| --- | --- |
| `robot_id` | Robot identifier |
| `joint_q[12]` | Joint angle |
| `joint_qd[12]` | Joint velocity |
| `joint_tau[12]` | Joint torque |
| `quat[4]` | IMU quaternion |
| `rpy[3]` | roll, pitch, yaw |
| `omega[3]` | Angular velocity |
| `acc[3]` | Acceleration |
| `v_des[3]` | Desired velocity |
| `omega_des[3]` | Desired angular velocity |
| `mode` | Current control mode |

## Generate Types

After modifying `.lcm` files, run:

```bash
bash scripts/generate_lcm_types.sh
```

## Safety Note

Message field dimensions, joint order, and units must remain consistent. Commands with wrong dimensions or wrong joint order from external algorithms may cause dangerous hardware motion.
